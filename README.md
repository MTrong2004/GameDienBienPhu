# Game Hà Nội - 12 Ngày Đêm (Điện Biên Phủ Trên Không)

Trò chơi mô phỏng chiến dịch lịch sử 12 ngày đêm "Điện Biên Phủ trên không" (18/12 - 29/12/1972), tái hiện cuộc chiến đấu bảo vệ bầu trời Hà Nội của quân và dân ta trước pháo đài bay B-52.

## 🚀 Cách chơi
- Chạy trực tiếp tệp `start-game.bat` trên Windows để khởi động server cục bộ và mở game trên trình duyệt.
- Hoặc mở tệp `h_n_i_12_ng_y_m_18_12_29_12_1972.html` trực tiếp bằng trình duyệt web hiện đại (hỗ trợ HTML5 Canvas, Web Audio API, Three.js).

## 🛠 Công nghệ sử dụng
- **HTML5 Canvas / Three.js 3D**: Đồ họa không gian chiến trường, radar, mô hình máy bay và tên lửa SAM-2.
- **Tailwind CSS**: Giao diện điều khiển, radar HUD và buồng lái.
- **Web Audio API**: Hệ thống âm thanh chiến đấu, còi báo động phòng không, âm thanh động cơ phản lực và phóng đạn.
